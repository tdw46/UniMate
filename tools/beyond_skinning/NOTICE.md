# Beyond skinning engine

BVT Solver and Hallway Solver use the same independently reconstructed engine.
No original autoskin binary is included or loaded. Tyler reports author permission
for the autoskin_core 0.10.110 recovery and use. Compatibility version metadata
identifies that reference, while the package version is 0.1.0.

The reconstruction snapshot is preparation-217. Python orchestration is included
here; native Rust/WGSL sources and locked dependencies are in native-source.zip.
Dependency notices are in dependency-licenses.zip. Preserve existing attribution
when redistributing. The new Blender integration uses GPL-3.0-or-later.

Full API parity, every-character artistic acceptance and all supported Blender
integration gates are separate from the qualified routes. No source-speed-parity
claim is made. Original source weights are never binding inputs.
